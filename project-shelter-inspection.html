Shelter Inspection App

My final year project with a real client: New Hope Community Services, a Singapore social service agency that runs shelters for the homeless. I improved their shelter inspection web app and turned its live inspection data into charts that help inspectors see which shelters need attention.

Role
Developer
Team
Solo
Duration
Sep – Nov 2022
Tech
ASP.NET, C#, JavaScript, SQL

The brief

New Hope already had a web app for inspecting their shelters. My task was to improve its existing functions and build new ones, so their team could run their shelters more effectively.

What I built

  • Shelter management: added pages to add new shelters and update existing ones.
  • Easier navigation: added back buttons throughout the app and fixed a pagination bug.
  • New charts from live data: designed charts for inspection type (day or night), outstanding follow-ups and inspection ratings.
  • Reorganised statistics: split one crowded Statistics page into two, one for individual shelters and one for all shelters.
  • One filter instead of many: replaced the separate drop-down on every chart with a single shelter selector, so inspectors see all of a shelter’s charts at once.

Choosing what to chart

Besides reviewing what data the live system collected, I imagined myself as an inspector and asked what I would want to know at a glance. That led to three new charts:

  • Inspection type (day/night): shows when inspections tend to happen.
  • Inspection follow-ups: a reminder of how many inspections still have follow-ups to complete.
  • Inspection rating: low ratings show which shelters need more attention.

What I learned

Working solo on a live system meant learning C#, JavaScript and SQL inside an existing codebase, and debugging Visual Studio errors on my own. It taught me to read and extend someone else’s code, and to design features from the user’s point of view.
